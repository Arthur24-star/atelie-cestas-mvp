# Ateliê de Cestas e Presentes Personalizados

MVP acadêmico para apoiar a montagem de pedidos de cestas e presentes personalizados.

## Funcionalidades previstas
- Catálogo de insumos e cálculo de subtotal.
- Dados do cliente e data de entrega.
- Resumo do pedido e preparação de mensagem para WhatsApp.

## Tecnologias
- Python e FastAPI
- SQLite com SQLAlchemy
- HTML, CSS e JavaScript
- Pytest

## Executar localmente
1. Crie e ative um ambiente virtual.
2. Instale as dependências: `pip install -r requirements.txt`
3. Inicie: `uvicorn app.main:app --reload`
4. Acesse `http://127.0.0.1:8000`.

## Testes
Execute `pytest`.
